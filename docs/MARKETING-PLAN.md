# แผนการตลาด Voscene — ภาพรวม

> เจ้าของอนุมัติ 2026-09-27 · ใช้คู่กับ `docs/MARKETING-GUIDE.md` (ถ้อยคำที่ใช้ได้/ห้ามใช้ · นิยามตัวเลข)
>
> **ขอบเขตหลังบ้านเว็บ (เจ้าของ 27 ก.ย.):** ใช้ **เตรียมสื่อการตลาด และมอนิเตอร์สื่อ เท่านั้น**
> งานขาย การติดตามลูกค้า รายชื่อเป้าหมาย และพันธมิตร **ทำนอกเว็บ** (ทีมคุยกับลูกค้าใน LINE / โทร)
> แผนด้านล่างเป็นภาพรวมธุรกิจ — ส่วนที่ไม่ใช่สื่อ **อย่าสร้างเป็นฟีเจอร์ในหลังบ้าน**
>
> **ไม่มีการนัด Demo หรือสาธิต** — ยังไม่มีชุดสาธิตการควบคุมอุปกรณ์จริง ใช้ **“นัดปรึกษาออกแบบระบบ”** แทนทุกที่
> คลิปที่ใช้ได้คือ **บันทึกหน้าจอซอฟต์แวร์** ห้ามสื่อว่าเป็นการควบคุมอุปกรณ์จริงในคลิป

## เป้าหมายธุรกิจ

หาลูกค้าที่ต้องการระบบควบคุมเสียง แสง และภาพ โดยเน้น

> **“รับออกแบบระบบควบคุมห้องประชุม — รวมเสียง แสง ภาพ สั่งงานในปุ่มเดียว”**

## ลำดับช่องทางขาย (ภาพรวม)

| ลำดับ | ช่องทาง | วิธีเข้าหา | เกี่ยวกับเว็บ/หลังบ้านไหม |
|---|---|---|---|
| 1 | ลูกค้าเดิมของ CSI | เสนอเพิ่มระบบควบคุมให้ห้องเดิมใช้งานง่ายขึ้น — ตรวจอุปกรณ์ก่อน | นอกเว็บ · ใช้สื่อจากคลังเนื้อหา / หน้าปลายทางชุด 2 ได้ |
| 2 | พันธมิตร — ติดตั้ง AV, IT, เครือข่าย, ระบบอาคาร, ผู้รับเหมา | “คุณรับงานติดตั้ง เราช่วยออกแบบและเชื่อมระบบควบคุม” | นอกเว็บ · สื่อสำหรับพันธมิตรเตรียมในคลังเนื้อหา |
| 3 | Google Search Ads | จับคนที่ค้นหาวิธีแก้ปัญหาหรือผู้รับออกแบบ | แคมเปญ + ลิงก์ติดตาม + ค่าโฆษณา + รายงาน |
| 4 | เข้าหาองค์กรรายแห่ง | ทีม IT ผู้ดูแลอาคาร ผู้ดูแลห้องประชุม | นอกเว็บ |
| 5 | กลุ่ม Facebook เฉพาะทาง | คลิปหน้าจอ / กรณีแก้ปัญหา | การตลาด → กลุ่ม Facebook |
| 6 | Facebook Page, TikTok, YouTube | แสดงการใช้งานจากหน้าจอ แล้วพาไป **นัดปรึกษาออกแบบ** | เนื้อหา + ลิงก์ติดตามต่อโพสต์ + รายงาน |

## ข้อเสนอหลัก

| ข้อเสนอ | บริการในระบบ | เงื่อนไขที่ต้องเขียนทุกครั้ง |
|---|---|---|
| เปิดห้องประชุมพร้อมใช้ในปุ่มเดียว | `one_touch` | ควบคุมอุปกรณ์ที่รองรับและผ่านการตั้งค่าแล้ว |
| รวมการควบคุมอุปกรณ์เดิมไว้บนหน้าจอเดียว | `single_panel` | ตรวจรุ่น พอร์ต โปรโตคอลก่อน — ไม่รับประกันว่าใช้ของเดิมได้ทั้งหมด |
| ควบคุมและดูสถานะหลายห้องจากศูนย์กลาง | `multi_room` | สูงสุด 20 ห้องต่อชุดควบคุม · ทุกห้องอยู่ในเครือข่ายเดียวกัน |
| สำหรับพันธมิตร | `integrator` | **ห้ามระบุส่วนลด ส่วนแบ่ง หรือเงื่อนไขราคา** — เจ้าของกำหนดรายกรณี |

**CTA หลัก:** “ส่งรายการอุปกรณ์เพื่อประเมินการเชื่อมต่อ” และ “นัดปรึกษาออกแบบระบบ”

## หลังบ้านเว็บ — เตรียมสื่อ + มอนิเตอร์สื่อ

**เตรียมสื่อ**
- แคมเปญ + ลิงก์ติดตามเฉพาะช่องทาง/โพสต์ (มีเดิม) · ช่องทางเพิ่ม **YouTube** (2026-09-27)
- คลังเนื้อหา + ปฏิทิน · จัดหมวดตาม **บริการ** และ **กลุ่มเป้าหมาย** (ลูกค้าเดิม · ผู้ดูแลห้อง · ทีม IT · ฝ่ายอาคาร · พันธมิตร) — กรองได้
- **แม่แบบตั้งต้น** (ปุ่ม “เริ่มจากแม่แบบ” ตอนสร้างเนื้อหาใหม่ — แนวทาง ไม่ใช่โพสต์ ไม่เผยแพร่เอง):
  1. ก่อน–หลัง: จากหลายรีโมตเป็นหน้าควบคุมเดียว
  2. คลิปหน้าจอควบคุม: กดปุ่มเดียวแล้วซีนทำงาน *(แทน “คลิปสาธิตอุปกรณ์ทำงานจริง”)*
  3. แก้ปัญหาผู้ใช้เปิดห้องประชุมไม่เป็น
  4. ดูแลหลายห้องจากจุดเดียว สำหรับทีม IT
  5. เพิ่มระบบควบคุมในงานของผู้ติดตั้ง
- AI ช่วยร่าง: เตือนเมื่อมีคำว่า Demo/สาธิต หรือส่วนลด/ส่วนแบ่งพันธมิตร
- หน้าปลายทางแคมเปญ `/solutions/<รหัสแคมเปญ>`

**มอนิเตอร์สื่อ** (การตลาด → รายงานผล)
- คลิก LINE / คลิกโทร / ค่าโฆษณา / ค่าโฆษณาต่อคลิก LINE — แยกตามช่องทาง แคมเปญ เนื้อหา/โพสต์
- GA4 (`generate_lead` จากคลิก LINE/โทร) สำหรับ Google Ads / Meta

**ไม่อยู่ในหลังบ้าน (ทำนอกเว็บ):** รายชื่อเป้าหมาย · การติดตามลูกค้า · พันธมิตรและข้อตกลง · ผลการขาย/เหตุผลที่ไม่ซื้อ
ถ้าวันหนึ่งต้องการ ให้เจ้าของสั่งใหม่ — แบบร่างเคยทำแล้วเก็บเป็น patch (ดู HANDOFF 27 ก.ย.)

## แผนกิจกรรม 30 วันแรก

> ตัวเลขเป็น **เป้าหมายกิจกรรมที่ปรับได้** ไม่ใช่ผลลัพธ์จริง

| สัปดาห์ | กิจกรรม | ส่วนที่ใช้หลังบ้าน |
|---|---|---|
| 1 | เตรียมคลิปหน้าจอ เอกสารแนะนำ ข้อเสนอลูกค้า/พันธมิตร | คลังเนื้อหา (เริ่มจากแม่แบบ) |

| 3 | ทดลอง Search Ads และเผยแพร่คลิป/โพสต์ | แคมเปญ + ลิงก์ติดตาม · บันทึกค่าโฆษณา |
| 4 | ติดตาม นัดปรึกษา เสนอราคา · ดูผลสื่อแต่ละช่องทาง | รายงานผล (ส่วนสื่อ) |

## ขอบเขต

- ระบบไม่ติดต่อบุคคล ไม่โพสต์ ไม่เปิดโฆษณา ไม่ใช้งบแทน
- กรอกเอง / นำเข้าไฟล์ ยังไม่เชื่อม API แพลตฟอร์ม
- ไม่มีข้อมูลจำลองในรายงานจริง
